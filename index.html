Pi extension

Parallel Pi tasks. Isolated safely.

Two agents in one checkout overwrite each other’s edits. Raw Git worktrees mean creating a branch and checkout, changing directories, relaunching Pi, tracking tasks, and cleaning up by hand.

Pi Worktree gives each task its own Git branch, checkout, and resumable Pi conversation—so each agent edits its own checkout.

pi install npm:pi-worktree-extension
pi
/worktree fix-auth

Already mid-conversation? Move it, history included.

Use /worktree fix-auth from an active Pi session to move the conversation into an isolated checkout. The task keeps its context; you do not need to start a new chat or restate the work.

Resume by task

Reopen a worktree and continue its latest Pi session.

Conservative cleanup

Removal refuses dirty or active worktrees and never deletes branches.

One task, one workspace

my-project/
├── primary checkout                 main
└── .pi/worktrees/
    ├── fix-auth/                    worktree-fix-auth
    ├── add-api-tests/               worktree-add-api-tests
    └── refactor-cache/              worktree-refactor-cache

Commands

/worktree fix-auth
Create or enter a task workspace.
/worktree-switch fix-auth
Switch to an existing workspace.
/worktree-list
See managed worktrees.
/worktree-exit
Return to the primary checkout.
/worktree-remove fix-auth
Remove a clean, inactive checkout.

The optional pi -w fix-auth shell launcher starts or resumes a task directly from a terminal.
