Pi extension

Parallel Pi tasks. Isolated safely.

Pi Worktree gives every coding task its own Git branch, checkout, and resumable Pi conversation—so agents never overwrite each other.

pi install npm:pi-worktree-extension
pi
/worktree fix-auth
Install from npm View on GitHub

One task, one workspace

main checkout      review and integrate work
fix-auth           investigate authentication
add-api-tests      add regression coverage
refactor-cache     explore a larger change

Each worktree has separate files and its own branch. Continue a task later without rebuilding its Pi context.

Resume by task

Reopen a worktree and continue its latest Pi session.

Move context

Move an active Pi conversation into an isolated worktree.

Stay safe

Cleanup refuses dirty or active worktrees and never deletes branches.

Commands

/worktree fix-auth        create or enter a task workspace
/worktree-switch fix-auth switch to an existing workspace
/worktree-list            see managed worktrees
/worktree-exit            return to the primary checkout
/worktree-remove fix-auth remove a clean, inactive checkout

The optional pi -w fix-auth shell launcher starts or resumes a task directly from a terminal.
