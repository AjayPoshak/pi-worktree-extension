# List Worktrees

- Use `/worktree-list`.
- Present a simple selectable list sorted by recency.
- Show each name, clean/dirty state, and branch.
- Do not show paths.
- Use arrows and Enter to select; Escape cancels.
- Switch to the selected worktree with `/worktree <name>`.
